# Skill: react-tailwind-feature-builder

## Name
react-tailwind-feature-builder

## Description
Builds and refines frontend features using React, Next.js App Router, and Tailwind while preserving design consistency, responsiveness, and accessibility.

## When to Activate
- Creating or updating UI features in `app/**` and `components/**`.
- Modifying Tailwind styles, reusable UI primitives, or page layouts.
- Implementing interactive states tied to backend APIs.

## Step-by-Step Execution Plan
1. **Load required context** from `context/`.
2. **Clarify UX scope**
   - Define target user flow, states, and acceptance criteria.
3. **Map impacted UI surface**
   - Identify pages, components, hooks/stores, and translations affected.
4. **Design implementation**
   - Reuse existing component patterns and utility classes.
   - Keep style changes aligned with current design language.
5. **Implement incrementally**
   - Build UI, wire interactions, and handle loading/empty/error states.
6. **Validate quality**
   - Check responsive behavior, keyboard access, and visual regressions.
7. **Coordinate contracts**
   - Confirm frontend expectations with backend/testing agents.
8. **Document changes**
   - Update relevant docs/context and append a short note in `.ai-memory/agent-notes.md`.
